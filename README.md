# 🌍 EcoTrueque: Plataforma Web de Intercambio Responsable

**EcoTrueque** (o Trueque Ecológico) es una aplicación web orientada a fomentar el intercambio responsable de bienes y recursos dentro de una comunidad. Al promover la economía circular y la reducción de residuos, la plataforma crea un entorno seguro donde los objetos en buen estado encuentran una segunda vida a través de la colaboración social.

## 🚀 Propósito del Proyecto
El proyecto atiende el problema del desperdicio de artículos útiles y el consumo excesivo. Busca reducir la contaminación y fortalecer la cooperación comunitaria mediante una plataforma digital que facilite el trueque justo y accesible, especialmente para personas con recursos limitados.

### Beneficios Principales:
* **Acceso a bienes sin dinero:** Permite adquirir lo necesario mediante el intercambio directo.
* **Ahorro económico:** Fomenta una economía solidaria y el ahorro familiar.
* **Reducción de residuos:** Disminuye la saturación de basureros al evitar el desecho de objetos funcionales.
* **Convivencia social:** Fortalece la confianza y la interacción entre vecinos, estudiantes y colectivos.

## 🛠️ Tecnologías Utilizadas
El sistema se basa en una arquitectura robusta y eficiente:

* **Framework:** [KumbiaPHP](https://kumbiaphp.com/) utilizando el patrón **MVC (ActiveRecord)** para una lógica de negocio limpia.
* **Lenguajes:** PHP para el backend; HTML, CSS y JavaScript para una interfaz **Frontend responsiva**.
* **Base de Datos:** **MySQL / MariaDB** para el almacenamiento seguro de usuarios, artículos y mensajes.
* **Servidor:** Apache, gestionado mediante **aaPanel**.
* **Monitoreo:** Integración con **Matomo Analytics** para estadísticas de uso.

## 📋 Funcionalidades de la Aplicación

### Módulos para el Usuario:
1. **Registro e Inicio de Sesión:** Cuentas seguras para participar en la comunidad.
2. **Publicación de Artículos:** Permite subir objetos con descripción, categoría e imágenes.
3. **Catálogo de Trueques:** Visualización general de todos los artículos disponibles.
4. **Sistema de Mensajería:** Comunicación directa entre usuarios para acordar el intercambio.
5. **Gestión de Intercambios:** Lógica para aceptar, rechazar o marcar como completado un trueque.
6. **Sistema de Reportes:** Herramienta para denunciar contenido inapropiado y mantener la seguridad.

### Gestión Administrativa:
* **Panel de Control (AdminLTE):** Gestión centralizada de usuarios, moderación de artículos reportados y visualización de estadísticas generales del sistema.
